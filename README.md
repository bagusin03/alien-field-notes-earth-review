An alien tourist's one-line review of Earth, for the make.fun "Alien Field Notes: The Two Day Earth Review" bounty. `main.ts` writes a single 143-character line to `/output/entry.txt` — nothing else. The joke is the alien's angle on sleep: humans shut down for eight hours a night, wake up exhausted, and call it rest. Fully offline and deterministic: no network, no clock, no randomness, standard library only.

> Earth: the locals shut down for eight hours every night, then wake up exhausted and call it rest. Lovely oceans, though. 3/5 — would nap again.

## Run it

```sh
node main.ts
```
